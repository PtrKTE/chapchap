### Problèmes résolus durant le déploiement

     dans /etc/php/8.3/fpm/pool.d/app.chapchap-ci.com.conf

2. RolePermissionSeeder échoue (rôle 'gerant' inexistant)
   - Fix : création manuelle via tinker + shield:super-admin --user=1

3. git pull "dubious ownership"
   - Fix : git config --global --add safe.directory [path]

4. Dashboard vide en production
   - Cause : profil utilisateur non assigné sur le compte production
   - Fix : assigner le profil "Gérant" via Utilisateurs → Modifier → Sauvegarder
   - Prévention : trait WidgetVisibleParProfil — les super_admin voient
     tous les widgets même sans profil métier assigné (commit bdf631d)
