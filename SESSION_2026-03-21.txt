### Problèmes résolus durant le déploiement

1. open_basedir restriction (HTTP 500)
   - Cause : Hestia limitait PHP au dossier public_html/
     mais le projet est dans project/ (hors des chemins autorisés)
   - Fix : ajout de /home/Tetchi/web/app.chapchap-ci.com/project
     dans /etc/php/8.3/fpm/pool.d/app.chapchap-ci.com.conf
   - Commande : systemctl restart php8.3-fpm

2. RolePermissionSeeder échoue (rôle 'gerant' inexistant)
   - Cause : shield:generate crée les permissions mais pas les rôles métier
   - Fix : création manuelle via tinker
     $roles = ['gerant','resp_operations','gestionnaire_stock',
               'agent_production','commercial'];
     foreach($roles as $r) { Role::firstOrCreate([...]) }

3. super_admin non assigné (403 Forbidden)
   - Fix : php8.3 artisan shield:super-admin --user=1
           php8.3 artisan shield:generate --all --force

4. git pull "dubious ownership"
   - Cause : deploy.sh lancé en root alors que le projet appartient à Tetchi
   - Fix : git config --global --add safe.directory [path]
