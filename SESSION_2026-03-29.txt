--------------------------------------------------------------------------------

pour bénéficier d'un environnement de développement plus moderne et mieux géré.


2. ÉTAT AVANT LA MIGRATION (XAMPP)

- Projet           : /Applications/XAMPP/xamppfiles/htdocs/chapchap/

  - Socket         : /Applications/MAMP/tmp/mysql/mysql.sock

4. ÉTAPES RÉALISÉES
--------------------------------------------------------------------------------

  [1] Arrêt de XAMPP
      - Apache XAMPP arrêté via le XAMPP Manager
      - MySQL XAMPP arrêté via : mysqladmin -u root shutdown

  [2] Export de la base de données depuis XAMPP
      Commande utilisée :
        /Applications/XAMPP/xamppfiles/bin/mysqldump \
          -u root --default-character-set=utf8mb4 \
          --single-transaction --routines --triggers \
          chapchap > /tmp/chapchap_backup.sql
      Résultat : fichier de 140K, export complet (36 tables)

  [3] Copie du projet vers MAMP
      Commande :
        cp -R /Applications/XAMPP/xamppfiles/htdocs/chapchap \
              /Applications/MAMP/htdocs/chapchap
      Résultat : 142M copiés avec succès

  [4] Démarrage de MAMP Pro
      - MAMP Pro lancé via l'application
      - MySQL 8.0 sélectionné, PHP 8.4.17 configuré
      - Apache sur port 8888, MySQL sur port 8889 (socket only)

  [5] Création et import de la BDD dans MySQL 8.0
      Commandes :
        # Connexion MySQL MAMP
        /Applications/MAMP/Library/bin/mysql80/bin/mysql \
          -u root -proot --port=8889 \
          --socket=/Applications/MAMP/tmp/mysql/mysql.sock

        # Créer les bases
        CREATE DATABASE chapchap CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
        CREATE DATABASE chapchap_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

        # Importer le dump
        /Applications/MAMP/Library/bin/mysql80/bin/mysql \
          -u root -proot --port=8889 \
          --socket=/Applications/MAMP/tmp/mysql/mysql.sock \
          chapchap < /tmp/chapchap_backup.sql

      Résultat : 36 tables importées, 1.89MB, 17 produits, 1 utilisateur

  [6] Mise à jour du fichier .env
      Fichier : /Applications/MAMP/htdocs/chapchap/.env

      Modifications :
        APP_URL=http://localhost:8000
        DB_HOST=localhost
        DB_PORT=8889
        DB_DATABASE=chapchap
        DB_USERNAME=root
        DB_PASSWORD=root
        DB_SOCKET=/Applications/MAMP/tmp/mysql/mysql.sock

      Clé importante : DB_SOCKET permet à Laravel de se connecter via socket Unix
      car MySQL MAMP Pro fonctionne en mode skip_networking (TCP désactivé).

  [7] Configuration du PATH système
      Fichier créé : /Users/patricktetchi/.zshrc
      Contenu ajouté :
        export PATH="/Applications/MAMP/Library/bin/mysql80/bin:$PATH"
        export MYSQL_SOCKET="/Applications/MAMP/tmp/mysql/mysql.sock"

      Résultat :
        - PHP  : 8.4.8 (Homebrew)   → which php = /usr/local/bin/php
        - MySQL: 8.0.44 (MAMP)      → which mysql = /Applications/MAMP/.../mysql

  [8] Vidage des caches Laravel
      Commandes :
        cd /Applications/MAMP/htdocs/chapchap
        php artisan config:clear
        php artisan cache:clear
        php artisan route:clear
        php artisan view:clear

  [9] Correction des permissions
      Commande :

  [10] Tests de vérification
      - php artisan db:show        → MySQL 8.0.44, 36 tables, 1.89MB ✓
      - php artisan migrate:status → 28 migrations, toutes "Ran" ✓

5. PROBLÈME RENCONTRÉ : Virtual Host MAMP Pro
--------------------------------------------------------------------------------
Tentative de configuration d'un Virtual Host chapchap.local via MAMP Pro.

  Problème 1 : Le sélecteur de fichiers MAMP Pro ne permettait pas de naviguer
               en dehors de ~/Sites/ → résolu via Cmd+Shift+G (chemin manuel)

  Problème 2 : MAMP Pro régénère son httpd.conf à chaque redémarrage →
               les modifications manuelles dans httpd.conf sont écrasées

  Problème 3 : Tentative de symlink ~/Sites/localhost → chapchap/public
               → Refusé par Apache (AH00037: Symbolic link not allowed)

  Conclusion : Virtual Host abandonné pour le moment.
  Solution retenue : php artisan serve (standard Laravel, port 8000)


6. CONFIGURATION DE TRAVAIL FINALE
--------------------------------------------------------------------------------
